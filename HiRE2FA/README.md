# HiRE2FA
Utility for converting from HiRE coarse grained model to all-atom structures.

## Quickstart (without pip)
```bash
### must be run under "HiRE2FA" as current directory
python3 main.py input_cg.pdb output_fa.pdb
```

## Quickstart (with pip)
```bash
### can be run under any current directory
pip install hire2fa
hire2fa input_cg.pdb output_fa.pdb
```
